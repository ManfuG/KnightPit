Stockfish networks are distributed under the same GPLv3 terms as the engine.

To rebuild this flavor, extract the source archive, copy the adjacent
nn-61e7af4bb97d.nnue into the extracted src/ directory, install Emscripten 6.0.9
(as required by this release's build.js) and its standard build prerequisites,
then run from the extracted source root:
  npm install --ignore-scripts
  node build.js --lite --single-threaded --no-split -f --strict-em-check

The build tools are not required to run the bundled engine. Source and network
files are provided for GPL source availability and are not loaded at runtime.
Keep this directory, source archive, network, license and attribution together
when redistributing the engine, including static websites and Android packages.
The SHA256SUMS file identifies each unmodified downloaded artifact.
